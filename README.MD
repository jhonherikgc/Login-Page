Este projeto é uma interface de autenticação moderna que utiliza animações dinâmicas para guiar a interação do usuário. Desenvolvido com foco em tipagem estática e performance.

---

## 🚀 Tecnologias

* **Framework:** React (Vite)
* **Linguagem:** TypeScript
* **Animações:** Lottie-web (arquivos JSON)
* **Estilização:** CSS Customizado

## 📁 Organização de Arquivos

Conforme a estrutura do repositório:

* `src/assets/`: Armazena o `Login Character Animation.json`.
* `src/styles/`: Contém `loginPage.css` e `createAccount.css`.
* `src/loginPage.tsx`: Componente lógico da tela de entrada.
* `src/createAccount.tsx`: Componente de registro de novos usuários.

---

## ⚠️ Limitações de Layout

> ⚠️
> **Atenção:** Este projeto foi construído sob demanda para telas específicas.
> * **Resolução fixa:** Otimizado apenas para **1920x1080**.
> * **Responsividade:** O projeto **não é responsivo** no momento.
> * **Validações:** O projeto **não possui REGISTRO / LOGIN OFICIAL**, ou seja, apenas **DESIGN**.

## 🛠️ Instalação e Uso

Para configurar o ambiente e executar o projeto, utilize os comandos **bash** abaixo:

1. **Clonar o repositório**
   ```bash
   git clone git@github.com:jhonherikgc/Login-Page.git

2. **Baixar dependencias**
    ```bash
    npm install

3. **Rodar projeto**
    ```bash
    npm run dev
